# Workflow templates

These JSON workflows are copied from the installed `comfyui-workflow-templates` package distributed for ComfyUI. They contain graph data only, not model weights. Confirm the package's current license before redistributing updated copies.

- `t2v-standard.json`: text-to-video.
- `i2v-standard.json`: image-to-video.
- `i2v-continuation.json`: continue an existing clip.
- `r2v-standard.json`: reference-to-video.

Templates may require newer ComfyUI nodes than an older installation. Open in ComfyUI and resolve missing-node/model notices before queueing.
